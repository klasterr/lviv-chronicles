# Львів: прогулянка проспектом Свободи

Веб-гра від першого лиця: центр Львова (~1,2 × 0,95 км) побудований з даних OpenStreetMap (`export.geojson`).
Можна ходити, бігати, стрибати, літати, сидіти на лавках, їздити на самокатах Bolt, грати в шахи з двома дідусями і заходити в McDonald's, щоб зробити замовлення.
Найдокладніше змодельований проспект Свободи: від Оперного театру до пам'ятника Шевченку.

Стек: TypeScript + Vite + Three.js. Шахи: `chess.js` і власний рушій у Web Worker.

## Швидкий старт

```
npm install
npm run dev          # http://localhost:5173 , клік по екрану, щоб почати
npm run build        # перевірка типів + production-збірка в dist/
npm test             # колізії, вибір лавок, парковки, шаховий рушій
npm run perf         # збірка + перевірка бюджетів швидкодії в headless Chrome
```

Потрібні Node 20.19+ (перевірено на Node 24) і (для `npm run perf`) встановлений Chrome. Шлях можна задати змінною `CHROME=/шлях/до/chrome`.
Готові дані (`public/city.json`, текстури, фото) вже лежать у репозиторії, тож для запуску мережа не потрібна.

### Параметри URL
| Параметр | Дія |

## Керування

| Дія | Клавіші |
|---|---|
| Рух / біг | `W A S D` або стрілки / `Shift` |
| Огляд | миша (після кліку по екрану курсор захоплюється, `Esc` — пауза) |
| Звук | `M` — вимкнути / увімкнути; звук синтезується на льоту (кроки, самокат, McDonald's, гітарист, фонтан), без аудіофайлів, і вмикається після першого кліку |
| Стрибок | `Space` (близько 1 м) |
| Політ | `F` або подвійний `Space`; у польоті `Space` вгору, `C` вниз, `Shift` швидше; рухаєтесь туди, куди дивитесь |
| Сісти на лавку | прицілитись і клікнути лівою кнопкою (до 4 м). Підвестись: рух / `Space` / клік |
| Самокат Bolt | `E` біля самоката — сісти, `E` — злізти; `R` — відправити покинутий самокат на парковку |
| Їзда на самокаті | `W` газ, `S` гальмо, `A`/`D` поворот; спідометр у км/год справа внизу |
| Шахи | сісти на вільну лавку навпроти дідуся, `G` — відкрити дошку |
| Музикант | біля пам'ятника Шевченку підійти до кейса гітариста (до 1,8 м, з боку слухачів), `E` — кинути чайові (10 ₴) |
| Предмети | прицілитись на предмет (3 м): `E` — взяти, `T` — весь піднос, `Q` — кинути (розбивається й зникає); рук дві: піднос займає обидві |
| McDonald's | зайти в двері (дивлячись на них); `E` біля каси чи кіосків — замовлення; вийти — підійти до дверей зсередини |

### Телефон (горизонтальна орієнтація)

На телефонах і планшетах (`pointer: coarse`) замість клавіатури та миші з'являється екранне керування. Торкніться стартового екрана: гра піде на весь екран і, де браузер дозволяє, зафіксує горизонтальну орієнтацію.
У портретній орієнтації з'являється підказка повернути телефон.

| Елемент | Дія |
|---|---|
| Лівий палець (ліва ~40% екрана) | плаваючий джойстик: рух, до краю — біг |
| Правий палець (будь-де праворуч) | огляд |
| «Стрибок» (праворуч унизу) | стрибок |
| ✈ (праворуч угорі) | політ; у польоті з'являються ▲ ▼ для підйому й спуску |
| ☰ (ліворуч угорі) | пауза |
| Зелені кнопки над «Стрибком» | дії за обставин: «Сісти» / «Підвестися» (лавка вибирається прицілом по центру екрана), «Сісти на самокат» / «Злізти» / «На парковку», «Грати в шахи», «Зробити замовлення» / «Забрати замовлення» / «Кіоск» |

На самокаті джойстик працює так: вперед — газ, назад — гальмо, вбік — поворот; спідометр угорі посередині.
Для економії батареї та відеопам'яті на телефоні тіні та згладжування вимкнені, а роздільна здатність стартує з 1× (далі її підлаштовує адаптивний режим).
У ландшафті шахова дошка розкладається ліворуч, а заголовок, статус і кнопки — у стовпці праворуч.

### Самокати Bolt
Дві парковки по 6 самокатів: збоку від сухого фонтана (між водою та довгими лавками) і перед пам'ятником Шевченку.
Максимальна швидкість 40 км/год. Покинутий самокат стоїть там, де ви його залишили; `R` (до 8 м) відправляє його на власне місце
(їде по прямій зі швидкістю 6 м/с). Самокат не має колізій з іншими об'єктами, а зіткнення гравця зі стінами та деревами гасить швидкість.

### McDonald's (інтер'єр)
Двері ресторану в Пасажі Феллерів (проспект Свободи 35) ведуть усередину, як в інтер'єрах старих GTA: підійдіть до дверей (жовте коло) і дивіться на них — екран затемнюється,
і ви опиняєтесь в окремій кімнаті. Прямо перед дверима каса, за нею кухня; біля входу два кіоски самообслуговування, у залі столики-кабінки (на лавки можна сідати),
зліва сходи на другий поверх із ще чотирма кабінками. Касир видає замовлення: на касі `E` відкриває меню (бургери, курка й картопля, напої, десерти), після «Замовити» касир каже номер і суму,
рука рухається, а на прилавку з'являється піднос із окремими предметами (до 8 на замовлення): можна взяти все разом або по одному, носити й кидати. На кіоску замовлення оплачується одразу, а забрати його треба на касі (`E`). Ціни умовні. Вихід — підійти до дверей і дивитися на них.

### Шахи
На шахових столиках у східній зеленій смузі бульвару сидять двоє дідусів. Ви граєте білими, вони чорними. Гра зберігається, поки сторінка відкрита.

| Дідусь | Рівень | Як грає |
|---|---|---|
| Дід Степан | легкий | 30% ходів випадкові, решта: жадібний 1-ходовий вибір із шумом; не бачить відповідей, тому підставляє фігури |
| Дід Ярослав | складний | пошук alpha-beta до 4 напівходів із тихим пошуком (quiescence), ліміт часу 1,3 с, оцінка за матеріалом і таблицями позицій |

Піхота завжди перетворюється на ферзя. Усі правила (рокіровка, взяття на проході, мат, пат, нічия) забезпечує `chess.js`.

## Що є у світі

* **Місто з OSM:** 608 будівель (висота з `building:levels`/`height`, стиль фасаду за `start_date`, колір за `building:colour`), 582 дороги й
  тротуари з поверхнею за тегом `surface`, ширина проїжджої частини за `lanes`.
* **Фасади:** процедурні вікна поверх фото штукатурки, рустований цоколь, карниз; чотири будинки проспекту (№20 музей, №27, №29, №35) мають
  фото-фасади, випрямлені за чотирма кутами; ресторан McDonald's у Пасажі Феллерів (№35) намальований за адресою, OSM-вузлом і фото-довідкою.
* **Орієнтири:** Оперний театр (фото фасаду + купол), Ратуша (корпус + вежа з фото) — за ідентифікаторами OSM у `src/world/landmarks.ts`.
* **Проспект Свободи:** план розкладений за геометрією двох проїжджих частин із GeoJSON: площа Опери з сухим фонтаном-скрипкою (72 струмені),
  бульвар (променада з граніту, газони, 4 ряди каштанів і лип, лавки, чавунні ліхтарі), шаховий куток, питний фонтанчик, площа з пам'ятником
  Шевченку (постать, стела «Хвиля», два секторні газони, 12 дугових лав). Реальні об'єкти з OSM: 96 вивісок, лавки, смітники, велостійки,
  зупинки, зебри, тумби вздовж бордюру.
* **Ігрова механіка:** ходьба, біг, стрибок, політ, колізії зі стінами, дахи як опора (можна приземлитись), лавки, самокати, шахи.

## Структура репозиторію

```
export.geojson            вихідні дані OSM (не змінюється)
data/osm-poi.json         точкові об'єкти OSM (вивіски, лавки, дерева, ...) з Overpass
public/city.json          результат prepare-data: усе, що читає гра (метри)
public/tex/               PBR-текстури ambientCG (CC0), стиснуті WebP
public/photos/            фото-текстури Wikimedia Commons + CREDITS.txt
scripts/                  підготовка даних, фото, текстур; тести; перевірка швидкодії
.github/workflows/        автоматична публікація на GitHub Pages
src/                      код гри (див. docs/architecture.md)
docs/                     документація
```

## Публікація на GitHub Pages

Гра — суто статичний сайт (`dist/` ≈ 3,5 МБ), тож її можна безкоштовно хостити на GitHub Pages. На безкоштовному акаунті Pages працює лише з **публічними** репозиторіями.

1. Створіть репозиторій на GitHub і завантажте код: `git init -b main`, `git add .`, `git commit -m "Initial commit"`, `git remote add origin <url>`, `git push -u origin main`.
2. У репозиторії: **Settings → Pages → Source: GitHub Actions**.
3. Кожен push у `main` запускає `.github/workflows/deploy.yml` (`npm ci` → `npm run build` → публікація `dist/`). Сайт: `https://<користувач>.github.io/<репозиторій>/`.

Шляхи до ресурсів відносні (`base: './'` у `vite.config.ts`, адреси без початкового `/`), тому назва репозиторію не має значення, а збірка працює і з кореня домену.
Нові ресурси теж додавайте без початкового `/` (`'tex/…'`, `'photos/…'`). Локальна перевірка збірки: `npm run build && npx vite preview`.
`public/city.json`, текстури й фото лежать у репозиторії, тож CI не потребує мережі; щоб їх оновити, запустіть відповідні `npm run …` локально й закомітьте результат.

## Відомі обмеження

* Реальну швидкість (FPS, час GPU) не вимірювали: у headless Chrome працює програмний рендер SwiftShader. `npm run perf` перевіряє
  апаратно-незалежні бюджети (draw calls, трикутники, пам'ять текстур).
* Станом на останній запуск `npm run perf` три бюджети перевищені: пам'ять і розмір текстур та gzip-розмір JS через ліниві чанки шахів (див. «Стан перевірок» у `docs/architecture.md`).
* Фото деяких фасадів із 2016 року, зроблені взимку, навесні чи влітку, а дерева й трава осінні; фото містять власне освітлення.
* Опера й фасади з фото — плоскі панелі: збоку це видно.
* Немає: трамвайних проводів, дахів `roof:shape`, тераси McDonald's, відвідувачів у ресторані, рельєфу; звук лише синтезований (без семплів).
* Телефон: перевірено лише в емуляції Chrome (844×390, торкання), не на реальному пристрої. Джойстик цифровий (8 напрямків); лавка вибирається прицілом по центру екрана, а не торканням по ній; на iPhone Safari немає повноекранного режиму й блокування орієнтації.
* Самокат при поверненні на парковку їде по прямій і не обминає перешкод.
