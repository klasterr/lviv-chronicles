# Архітектура

Огляд для того, хто хоче змінити або розширити гру. Короткий опис, запуск і керування — у [`../README.md`](../README.md).

```
export.geojson ─┐
data/osm-poi.json ─┼─► scripts/prepare-city.ts ─► public/city.json ─┐
public/photos/*  ─┤      (layout-avenue, layout-poi, frontage)      │
public/tex/*     ─┘                                                  ▼
                                      src/main.ts ─► Game (рендер, цикл, системи)
                                         ├─ buildCity      будівлі, дороги, колайдери
                                         ├─ addProps       проспект: дерева, лавки, фонтан, пам'ятник
                                         ├─ addAvenue      фото-фасади, McDonald's, вивіски, OSM-об'єкти
                                         ├─ Player         ходьба / політ / лавка / самокат
                                         ├─ Sitting        клік по лавці
                                         ├─ Scooters       самокати Bolt
                                         ├─ Grandpas       дідусі + шахи (chess/*)
                                         └─ sky            небо, світло, тіні
```

## 1. Системи координат і конвенції

Усе в метрах. Початок координат — центр bbox GeoJSON, проєкція рівнопрямокутна (на ~1 км похибка зневажна, див. `prepare-city.ts`).

| Вісь | Напрям |
|---|---|
| `x` | схід |
| `z` | **південь** (північ = −z) |
| `y` | вгору |

**Кути.** Є дві конвенції, їх не можна плутати:

* **Об'єкти (`rotation.y = yaw`):** локальна вісь +z іде у світі як `(sin yaw, cos yaw)`, локальна вісь +x як `(cos yaw, −sin yaw)`.
  Перетворення локальне → світ: `x = px + lx·cos + lz·sin`, `z = pz − lx·sin + lz·cos` (так у `Colliders.addRect`, `props.ts`, `grandpas.ts`). «Обличчя» об'єкта — локальне +z.
* **Камера / напрям руху (`a`, також кут самоката):** вперед = `(−sin a, −cos a)`, вправо = `(cos a, −sin a)`.
  Тому об'єкт, що дивиться вздовж камери з кутом `a`, має `yaw = a + π` (так садять гравця: `yaw: bench.yaw + π`; самокат: `setFromAxisAngle(up, a + π)`).

**Геометрія будівель.** Зовнішнє кільце має додатну площу в `(x, z)`, отвори (двори) — від'ємну; зовнішня нормаль стіни `n = (dz, −dx)/len`.
Висота: `lm.h` (орієнтири) → `height` OSM → `building:levels × 3,3 м` → за замовчуванням ~4 поверхи (малі будівлі до 80 м² — 3,5 м).

## 2. Конвеєр даних (`scripts/`, запускається вручну)

| Скрипт (`npm run …`) | Вхід | Вихід | Мережа |
|---|---|---|---|
| `prepare-data` (`prepare-city.ts`) | `export.geojson`, `data/osm-poi.json` | `public/city.json` | ні |
| `poi` (`fetch-poi.ts`) | bbox із GeoJSON → Overpass API | `data/osm-poi.json` | так |
| `photos` (`prepare-photos.ts`) | Wikimedia Commons (за `facade-config.ts`) | `public/photos/*.webp`, `src/world/avenue/facades.generated.ts`, `public/photos/CREDITS.txt` | так |
| `textures` (`fetch-textures.ts` + `optimize-textures.mjs`) | ambientCG | `public/tex/*.webp` (стиснуті до потрібних розмірів) | так |

Допоміжні модулі: `layout-avenue.ts` (розкладка проспекту), `layout-poi.ts` (вивіски та об'єкти з OSM), `frontage.ts` (стіна будинку, що дивиться на проспект),
`facade-config.ts` (кути фото-фасадів, висоти).

### `public/city.json`
Тип — `CityData` у `src/world/city.ts`.

* `spawn {x, z, yaw}` — на початку бульвару за фонтаном, обличчям до опери (камерний yaw).
* `buildings[]`: `id` (OSM), `r` (кільця: зовнішнє + отвори), `h` (висота; 0 = невідома), `lv`, `t` (тип), `sd` (рік `start_date`), `rs` (`roof:shape`), `bc` (`building:colour`).
* `roads[]`: `p` (полілінія), `k` (`highway`), `s` (`surface`), `w` (ширина; для проїжджої частини з `lanes × 3,1 м`).
* `street` (`Street`): `trees [x,z,seed,kind]`, `benches [x,z,yaw,kind]` (0 парковa, 1 довга, 2 дугова), `lamps`, `fountain`, `chess` (столики `[x,z,yaw]`),
  `drinking`, `beds`, `ribbons` (смуги граніту й газонів), `plaza`, `monument`; плюс `AvenueData` з `layout-poi.ts`: `fronts`, `signs`, `osm{benches,bins,bikes,lamps,hydrants,stops,trees}`, `crossings`, `bollards`, `laneMarks`.

### Розкладка проспекту (`layout-avenue.ts`)
Усі довжини й ширини беруться з GeoJSON, текстовий опис дає лише склад об'єктів і розміри окремих речей.

1. Вісь бульвару — середина між двома проїжджими частинами (`highway=primary` — захід, `secondary` — схід, ім'я «проспект Свободи»), заміряна по `z` від фасаду опери (найпівденніша точка контуру) до центру пішохідного майданчика `way/356593298` (пам'ятник Шевченку). Довжина секції ≈ 307 м.
2. Зони масштабуються на `довжина / 430`: площа Опери 0–85, північна частина 85–220, середня (шахи) 220–350, площа пам'ятника 350–430 (у метрах опису).
3. Поперечний переріз у частках чистої ширини (ширина між проїжджими частинами мінус їхні напівширини, 49–59 м): 4,5/27 — променада (на кожен бік), до 10/27 — газон.
4. Об'єкти: клени на краях площі, чотири ряди каштанів/лип (крок 7,5 м, «шахматка»), лавки (крок 15 м у північній частині, 11 м у середній), ліхтарі (18 м), шахова група (6 столиків, у східній смузі), питний фонтанчик, пам'ятник (за напрямом осі) і стела, два секторні газони, 12 дугових лав.

## 3. Рантайм (`src/`)

### Завантаження (`main.ts`)
Порядок: матеріали + `city.json` → `buildCity` → `addProps` → `addAvenue` → ґрунт → небо → `Player` → системи (`player`, `Sitting`, `Scooters`, `Grandpas`, `sky`, `props`, `avenue`) →
`compileAsync` + один кадр за екраном завантаження → екран «Натисніть, щоб почати». Стартовий екран знову показується при втраті захоплення курсора (`unlock`), крім моменту, коли відкрита шахова дошка.
`window.game` і `window.perfReport()` доступні в консолі для налагодження.
Адреси ресурсів (`city.json`, `tex/…`, `photos/…`) **без початкового `/`**, а в `vite.config.ts` `base: './'`: так збірка працює з підадреси (GitHub Pages) і з кореня домену.

### Цикл (`game.ts`)
`System { update(dt); preRender?(camera) }`. `Game.frame(dt)` викликає всі `update`, потім `preRender` (відсікання інстансів), потім рендер. Є адаптивний pixelRatio (1,5 → 0,65, якщо середній кадр > 21 мс; `?nogov` вимикає),
обробка втрати контексту WebGL, пауза в прихованій вкладці (`Timer.connect`).

### Місто (`city.ts`, `meshbuilder.ts`, `materials.ts`)
* Будівлі: стіни в секціях «цоколь / середні поверхи / верхній поверх» (стиль фасаду за `start_date`), вертексний колір штукатурки, дах окремим матеріалом. Геометрія накопичується у `Chunks` (чанк 400 м, індексовані буфери,
  нормалі Int8, кольори Uint8).
* Фасади: **один** матеріал на всі стіни — масив текстур (`DataArrayTexture`), шар вибирає атрибут вершини `tile`. Плитка 512 px (`FACADE_RES`) = 1 вікно × 1 поверх, намальована на canvas поверх фото штукатурки.
  Додати власну плитку: `extraFacadeTiles[ключ] = (g, S) => …` + `mats.facadeLayer(ключ)`.
* Дороги: стрічки, матеріал за (`surface`, шар), `polygonOffset` розв'язує накладання тротуарів/проїзду/граніту/газону (шари: проїзд 0, пішохідна 1, доріжки 2, граніт 6, газон 7, фонтан 8, парковки 9).
* Колайдери (`colliders.ts`): рівномірна сітка 20 м; відрізки стін з висотою, контури будівель (висота даху для посадки), малі перешкоди (`addBox`, `addRect`), лавки (`addBench` + `rayBench`).

### Орієнтири (`landmarks.ts`)
Таблиця `LANDMARKS` за OSM-id: перевизначення висоти/поверхів/кольору/стилю/даху або повна заміна геометрії (`skipMesh` + `model`).
Опера: фото-панель фасаду з альфа-каналом (небо вирізане) + купол. Вежа Ратуші (65 м): низ із каменю, середина — фото на чотирьох гранях, карниз, флагшток. Корпус Ратуші: жовтий, сірий дах.

### Проспект
* `props.ts` — об'єкти розкладки: смуги землі (граніт/газон), дерева (`kind` 0/1/2), лавки трьох видів, ліхтарі, шахові столики, питний фонтанчик, сухий фонтан (вріз у формі скрипки + 72 анімованих струменя), пам'ятник Шевченку, стела, газони з бордюром.
  Усе, що повторюється, — через `instanced()` → `CulledInstances`.
* `avenue/` — шар «реального світу»: фото-фасади (`facades.generated.ts`), McDonald's (`ground-front.ts`: логотип і вивіски намальовані на canvas), вивіски (`signs.ts`, атлас 1024²), мапні лавки/смітники/велостійки/зупинки/дерева, зебри, тумби.
* `instancing.ts` (`CulledInstances`): матриці інстансів зберігаються на CPU, перед рендером у `InstancedMesh` копіюються лише видимі (frustum, відстань, LOD). Ніколи не ставте `frustumCulled = false` вручну.

### Гравець (`player/player.ts`)
Станові режими: ходьба, політ, лавка, самокат. Механіка: гравітація 22 м/с², стрибок 7,5 м/с, ходьба 4 / біг 8 м/с, політ 14 / 45 м/с (стеля 300 м), радіус 0,35 м, висота очей 1,7 (сидячи 1,2, на самокаті 1,8 м).
Колізії лише по горизонталі й тільки зі стінами, вищими за рівень ніг, тому на дах можна приземлитись, а низькі лавки можна перестрибнути.

* **Лавка** (`sitting.ts`): промінь погляду проти коробок лавок (`Colliders.rayBench`, до 4 м). `Player.sit()` плавно підводить камеру, `stand()` ставить гравця на 0,65 м перед лавкою. Підйом по події натискання клавіші, а не по опитуванню стану.
* **Самокат** (`scooters.ts`, `parking.ts`): `Player.mount()`/`dismount()`; `W` газ 3,5 м/с², `S` гальмо 7 м/с², накат 0,6 м/с², поворот 1,3 рад/с (пропорційно швидкості до 2,5 м/с), максимум **40 км/год** (`MAX_SPEED`).
  Самокати — один `InstancedMesh`; стани `parked → ridden → dropped → returning → parked`. Парковки — функція `parkingZones(street)` (тестується окремо).
* **Шахи** (`grandpas.ts`, `chess/`): два дідусі на лавках біля столиків 0 і 5. Опозиційну лавку визначає відстань 1,5–3,6 м до місця дідуся. Дошка (`chess/ui.ts`) вантажиться ліниво, пошук ходу — у Web Worker (`chess/worker.ts`).
  Рушій (`chess/engine.ts`): легкий — випадковий/жадібний; складний — негамакс alpha-beta, ітеративне поглиблення до 4 напівходів, тихий пошук, сортування MVV-LVA, ліміт 1,3 с. Інтерфейс масштабує клітинку під розмір вікна (`--s`).

### Небо й тіні (`sky.ts`)
Градієнтна сфера, туман 120–600 м, hemisphere + directional світло, одна карта тіней 2048² навколо гравця (±70 м), центр прив'язаний кроком 8,75 м і перемальовується лише при зміні кроку.

## 4. Перевірка

| Команда | Що перевіряє |
|---|---|
| `npx tsc --noEmit` / `npm run build` | типи (strict), збірка (`three` окремим чанком, чанки `ui` і `worker` для шахів завантажуються лише при першій партії) |
| `npm test` | `scripts/test-collide.ts`: колізії, дахи й двори, вибір лавки променем, розкладка парковок; `scripts/test-chess.ts`: мат в один хід, безкоштовний ферзь, пат, обидва рівні, складний не програє легкому |
| `npm run perf` | `scripts/perf.mjs` + `scripts/perf-budget.json`: draw calls, трикутники, програми, пам'ять текстур, розміри; детально в [`performance.md`](performance.md) |

Візуальна перевірка: headless Chrome через `puppeteer-core` (SwiftShader, ~3–6 fps, тому FPS не вимірюється). Камеру задають у консолі:
`game.camera.position.set(x, y, z); game.camera.rotation.set(pitch, yaw, 0, 'YXZ')`. Для тестів захоплення курсора вмикають вручну: `game.systems[0].controls.isLocked = true`.
Зручні точки огляду: `VIEWS` у `src/perf.ts`.

### Стан перевірок (останній запуск)
* `tsc`, `npm test`, `npm run build`: проходять.
* `npm run perf`: **три бюджети перевищені**, решта в нормі.
  * `texMB` — 78,5 при бюджеті 75 (фото-фасади й опера: фото опери 2048×1565 займає ~17 МБ у відеопам'яті);
  * `size.texKB` — 1686 при бюджеті 1400;
  * `size.jsGzipKB` — 193 при бюджеті 180: у суму входять ліниві чанки шахів (~28 КБ gzip), які не вантажаться на старті; початковий JS ≈ 172 КБ.
  Бюджети свідомо не піднімали; варіанти: стиснути фото опери й атлас фасадів або прийняти нові значення.
* FPS на реальному залізі не вимірювався.

## 5. Як розширювати

* **Нова система з тиканням** (NPC, час доби): клас із `update(dt)` → `game.systems.push(...)` у `main.ts`. Потрібен вигляд на кадр — `preRender(camera)`.
* **Новий повторюваний об'єкт:** `instanced(geo, mat, items, place, cast, { maxDist, lods })` у `props.ts`; для понад ~100 трикутників додайте дешевший LOD. Не додавайте нові матеріали на чанк — це нові draw calls.
* **Новий орієнтир:** запис у `LANDMARKS` за OSM-id (`h`, `floors`, `tint`, `style`, `roof`, `skipMesh`, `model`).
* **Фасад із фото:** додайте рядок у `scripts/facade-config.ts` (чотири кути в пікселях мініатюри 1920 px, висоти) і запустіть `npm run photos`; ширина панелі береться з GeoJSON, а не з фото.
* **Нова лавка / тип лавки:** зареєструйте через `colliders.addBench(x, z, yaw, hw, hd, h)` — вона стане клікабельною.
* **Новий дідусь / рівень:** запис у `GRANDPAS` (`grandpas.ts`: стіл, вигляд, ім'я, репліки) і, за потреби, новий `Level` у `chess/engine.ts`.
* **Нова парковка самокатів:** функція `zone(...)` у `parking.ts` та запис у `parkingZones`.
* **Нова вулиця за тим самим методом:** узагальнити `layout-avenue.ts` (зараз прив'язаний до двох ліній проспекту) — вісь, ширина й зони рахуються з геометрії.

## 6. Ідеї та відомі прогалини

* 3D-фігури на шаховому столику (зараз партія видна лише в накладці), промоція не на ферзя, відміна ходу, вибір кольору.
* Самокат: обхід перешкод при поверненні, колізії самокатів між собою, акумулятор/тариф.
* Нічне освітлення (ліхтарі вже мають світні лампи), трамвайні дроти, `roof:shape`, тераса McDonald's, звук.
* Свіжіші фронтальні фото для №27, №29 й опери; KTX2 для текстур (потрібен `toktx`/`basisu`).
* Мобільне керування й екранне джойстик-керування.
